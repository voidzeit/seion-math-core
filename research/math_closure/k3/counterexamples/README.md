# M3 counterexamples

No counterexample to the universal upper bound
$E_T^{\mathrm{proj}} \le (k-1)\rho M^{k-1}L_T = 2\eta$ was found for $k=3$
— not in the 255-row atlas (`docs/research/track_t_v5_terminal_status_k2_k3.md`),
and not in the two exact closed-form constructions derived this pass
(`../topology_chain.tex`, `../topology_branching.tex`): both
$3\eta^2\sqrt{1-\eta^2}$ (chain) and $\eta^2\sqrt{1-\eta^2}$ (branching)
are strictly below $2\eta$ for every $\eta\in(0,1]$ (ratios $3/4$ and
$1/4$ respectively at their shared maximum $\eta^\star=1/\sqrt2$, both
$<1$). This directory is empty of counterexamples deliberately, not by
omission — the universal bound itself remains unrefuted at $k=3$.
