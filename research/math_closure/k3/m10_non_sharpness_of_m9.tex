\section*{M10: M9's upper envelope $U_3(\eta)$ is not attained}
\label{sec:k3-m10}

\textbf{Revision note (this version repairs two errors found under
review; see \texttt{V5\_CLOSURE\_REPORT.md} for the full record).} The
first version of this note claimed a step ``$S_1\perp S_2$'' that does
not follow from the cited lemma alone -- the lemma gives $S_1\perp B$
for the \emph{un}-projected precursor $B:=\mu_2(R_1,c)$, and orthogonality
to $B$ does not survive an arbitrary projection $Q=I-P_2$ in general.
Section~\ref{sec:m10-step1} below replaces that step with a correct,
projector-independent argument. Second, and more importantly, the
original conclusion overclaimed a \emph{strict supremum} inequality
$C_{3,\mathrm{ind}}^P(\eta)<U_3(\eta)$ from a \emph{non-attainment} fact
alone -- a supremum can be approached without being attained (e.g.\
$\sup_{0<x<1}x=1$), so non-attainment at every point does not by itself
imply the supremum is strictly below $U_3(\eta)$. Section~\ref{sec:m10-conclusion}
states only what is actually proved.

\subsection*{A lemma about operator-norm-attaining directions}

\textbf{Lemma.} Let $N$ be linear (or a linear map restricted to a
2-dimensional subspace spanned by orthonormal $\hat u,\hat v$), with
$\|N(\cos\psi\,\hat u+\sin\psi\,\hat v)\|\le M$ for all $\psi$. If
$\|N(\hat u)\|=M$ exactly, then $N(\hat u)\perp N(\hat v)$.

\textit{Proof.} $f(\psi):=\|N(\cos\psi\,\hat u+\sin\psi\,\hat v)\|^2$
attains its maximum $M^2$ at $\psi=0$ (given), so $f'(0)=0$; direct
expansion $f(\psi)=\cos^2\psi\|N\hat u\|^2+\sin^2\psi\|N\hat v\|^2+
2\sin\psi\cos\psi\langle N\hat u,N\hat v\rangle$ gives
$f'(0)=2\langle N\hat u,N\hat v\rangle=0$. $\blacksquare$

\subsection*{Step 1 (repaired): $S_1$ and $S_2$ are never parallel}
\label{sec:m10-step1}

Setup as in M9: $D_1\perp R_1$ (Pythagorean, node 1), $N:=\mu_2(\cdot,c)$,
$\hat u:=D_1/\|D_1\|$, $\hat v:=R_1/\|R_1\|$. Suppose $T_1$ saturates
exactly at node 2, i.e.\ $\|N(\hat u)\|=M$. By the Lemma,
$S_1':=N(\hat u)\perp B:=N(\hat v)$. Let $Q:=I-P_2$ (\emph{any} orthogonal
projector complement -- no assumption on how $P_2$ is chosen) and
$S_2':=QB$ (the node-2-level precursor of $S_2$, before scaling by
$\|R_1\|$; $S_1=\|D_1\|S_1'$, $S_2=\|R_1\|S_2'$, and scaling by positive
reals never changes (non-)parallelism, so it suffices to argue about
$S_1',S_2'$).

\textbf{Claim.} If $S_1'\ne0$, then $S_2'$ is never a nonzero scalar
multiple of $S_1'$.

\textit{Proof.} Suppose $S_2'=\lambda S_1'$ for some scalar $\lambda\ne0$.
Since $S_2'=QB\in\mathrm{Range}(Q)$ and $\mathrm{Range}(Q)$ is a subspace,
$S_1'=S_2'/\lambda\in\mathrm{Range}(Q)$ too, so $QS_1'=S_1'$ (idempotence).
Using $Q$ self-adjoint ($Q^*=(I-P_2)^*=I-P_2=Q$, since $P_2$ is an
orthogonal projector):
\[
  \langle S_2',S_1'\rangle = \langle QB,S_1'\rangle = \langle B,QS_1'\rangle
  = \langle B,S_1'\rangle = \langle S_1',B\rangle^* = 0,
\]
the last equality because $S_1'\perp B$ (the Lemma). But also
$\langle S_2',S_1'\rangle=\langle\lambda S_1',S_1'\rangle=\lambda\|S_1'\|^2$
(real case; the complex case gives $\bar\lambda\|S_1'\|^2$, same
conclusion), which is nonzero since $\lambda\ne0$ and $S_1'\ne0$. This
contradicts the previous line. $\blacksquare$

This argument holds for \emph{any} $P_2$ -- it does not rely on a
specific construction of $P_2$, repairing the original version's gap.
Numerically stress-tested: 20{,}000 random trials (random $N$ built via
explicit SVD to genuinely saturate $M$ at $\hat u$, random orthogonal
projector $Q$ of random rank) found zero cases of $S_2'\parallel S_1'$
when $S_2'\ne0$ (\texttt{verify\_step1\_repair.py}, this session's
scratch directory -- not committed, purely a sanity check of the already-
complete proof above, not itself evidence).

\subsection*{Step 2: the root cannot realign them}

Let $N_3:=\mu_3(\cdot,d)$, $\hat s_1:=S_1/\|S_1\|$. Suppose $T_1$
\emph{also} saturates at the root: $\|N_3(\hat s_1)\|=M$. Decompose
(always possible, for any vector) $S_2=\alpha S_1+\beta\hat w$ with
$\hat w\perp S_1$, $\|\hat w\|=1$. Step 1 shows $\beta\ne0$ (a nonzero
orthogonal component -- exactly what ``$S_2$ not parallel to $S_1$''
means). By the Lemma applied at node 3 (with $\hat u=\hat s_1$,
$\hat v=\hat w$): $N_3(\hat w)\perp N_3(\hat s_1)$.

By linearity, $N_3(S_2)=\alpha N_3(S_1)+\beta N_3(\hat w)$, a sum of a
component parallel to $N_3(S_1)$ and a component orthogonal to it. We
check both possible cases for whether $N_3(\hat w)$ vanishes:

\textbf{Case A ($N_3(\hat w)\ne0$).} $N_3(S_2)\parallel N_3(S_1)$ requires
the orthogonal component to vanish: $\beta N_3(\hat w)=0$, so $\beta=0$
(since $N_3(\hat w)\ne0$) -- contradicting Step 1's $\beta\ne0$.

\textbf{Case B ($N_3(\hat w)=0$, a genuine degeneracy).} Here
$N_3(S_2)=\alpha N_3(S_1)$ automatically, parallel regardless of $\beta$
-- so triangle-parallelism alone does not force a contradiction in this
case. But we also need $T_2$ to saturate exactly at the root,
$\|N_3(S_2)\|=M\|S_2\|$. Compute both sides using $\|S_2\|^2=|\alpha|^2
\|S_1\|^2+|\beta|^2$ (Pythagorean, $S_1\perp\hat w$) and $\|N_3(S_1)\|=
M\|S_1\|$ (given):
\[
  \|N_3(S_2)\| = |\alpha|\,\|N_3(S_1)\| = |\alpha|\,M\|S_1\|,
  \qquad
  M\|S_2\| = M\sqrt{|\alpha|^2\|S_1\|^2+|\beta|^2}.
\]
Equality forces $|\alpha|^2\|S_1\|^2=|\alpha|^2\|S_1\|^2+|\beta|^2$, i.e.\
$\beta=0$ -- again contradicting Step 1.

Either way: \textbf{$T_1$ saturating at both node 2 and the root,
together with $T_2$ saturating at the root, is incompatible with the
triangle-inequality equality M9's derivation needs.} $\blacksquare$

\subsection*{Conclusion (corrected scope)}
\label{sec:m10-conclusion}

\[
  \boxed{\text{No admissible configuration attains $E_T^{\mathrm{proj}}=U_3(\eta)\rho M^2L_T$ exactly}}
\]
whenever the optimal $q^\star$ from M9 is interior or the boundary value
$q^\star=\rho$ with $\rho<M$ (i.e.\ whenever both $T_1,T_2$ are nonzero at
the optimum -- true for every $\eta\in(0,1)$). This is a genuine, proved
\texttt{PROVED\_NON\_ATTAINMENT} result: the supremum defining
$C_{3,\mathrm{ind}}^P(\eta)$, if it equals $U_3(\eta)$ at all, is not a
maximum -- no single configuration realizes it.

\textbf{What this does NOT establish (corrected from the previous
version).}
\[
  C_{3,\mathrm{ind}}^P(\eta) < U_3(\eta)
\]
is \textbf{not} proved by the above. Non-attainment at every individual
point is logically consistent with the supremum still equalling
$U_3(\eta)$, approached by a sequence of configurations that get
arbitrarily close without any single one reaching it (exactly as
$\sup_{0<x<1}x=1$ despite no $x<1$ attaining $1$). Closing this requires
one of:
\begin{description}
  \item[Route A (compactness)] restrict to a class where the extremal
    problem is known to live on a compact set (e.g.\ fixed ambient
    dimension and projector rank, closed and bounded law/leaf
    parameters) -- then a continuous objective attains its max on a
    compact set, and non-attainment at every point of that compact set
    would then force a strict gap \emph{for that restricted class}. This
    route needs the (currently open) dimension/rank reduction result to
    extend to the fully general class.
  \item[Route B (quantitative gap)] derive an explicit
    $E_T^{\mathrm{proj}}\le U_3(\eta)-\delta(\eta)$ with $\delta(\eta)>0$,
    which would give the strict inequality unconditionally, for every
    dimension/rank, without needing compactness at all. This is the
    stronger, more valuable route.
\end{description}
Neither route is completed by this note. \texttt{pareto\_frontier\_two\_
direction\_norm\_budget} (\texttt{k3\_non\_sharpness.py}) quantifies the
underlying trade-off (how the maximum jointly-supportable magnitude pair
for $(S_1,S_2)$ shrinks as their angle moves from $90^\circ$, M9's
regime, toward $0^\circ$, needed for triangle equality) and is exactly
the tool Route B would need, but the joint optimization over the pair
(magnitude allocation $q$, angle $\varphi$ between $S_1,S_2$) implied by
that trade-off has \textbf{not been solved} -- it is the natural next
problem (``M11'').

\textbf{A numerical search was also attempted and was inconclusive.} A
gradient-based (Adam + penalty method) adversarial search over raw
tensors (\texttt{m10\_k3\_search.py}, run this session, not committed to
the repository because its results are not trustworthy) failed to even
recover the already-known certified lower witness $L_3(\eta)$ at any
tested point -- e.g.\ at $\eta=0.5$ it found a normalized value of
$0.51$ against a known-achievable $L_3(0.5)=1.73$. This indicates a
methodology problem, not a mathematical finding, and is reported here
only so a future session does not repeat the same broken setup without
knowing it was already tried and discarded.

\textbf{Status.} \texttt{PROVED\_NON\_ATTAINMENT} (Steps 1-2 above,
repaired and numerically stress-tested). The strict supremum inequality
$C_{3,\mathrm{ind}}^P(\eta)<U_3(\eta)$ remains \texttt{OPEN} -- a
well-posed problem (Route A or B above), not established by this note.
