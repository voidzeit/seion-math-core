# P3 — dimension/rank status

The restricted k=2 gated-rotation identity was reproduced at
`(dimension, rank) = (2,1), (3,1), (3,2), (4,2)` and symbolically reports
`E_proj(eta)^2 = eta^4` in each case. The associated theorem dossier states
independence of dimension `n >= 2` and rank `1 <= r <= n-1` for that restricted
class.

This is not a universal extremizer reduction. The general statement that an
extremizer can always be confined to dimension two, rank one, or a bounded
active span remains open. No counterexample establishing a higher-dimensional
improvement was found in the reproduced baseline, but absence of a
counterexample is not a theorem.

```text
restricted class dimension/rank independence: PROVED_UNDER_ASSUMPTIONS
general dimension/rank reduction: OPEN
```
