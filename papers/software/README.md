# Reproducibility/software companion

The independently buildable companion manuscript is `main.tex`, with its
compiled PDF produced under `build/` by `scripts/build_companions.ps1`.

This manuscript workstream documents SEION Math Core as a verification suite.
It owns repository architecture, schemas, commands, hardware/environment
manifests, run indexes, figure/table provenance, release bundles, and recovery
procedures. These are software contributions and reproducibility evidence;
they are not substitutes for the mathematical theorem program in the research
paper.

Canonical contracts:

- `governance/RESEARCH_SOFTWARE_SPLIT.yaml`;
- `schemas/`;
- `experiments/`;
- `scripts/`;
- `artifacts/index/`.
