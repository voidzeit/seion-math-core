clean checkout of the commit. Anyone reproducing this must check out the branch rather than
using whatever happens to be in the working tree.

## 3. PDF text extraction

Text was extracted from each delivered PDF with `pdftotext` and checked for the mutilated
stems that a broken ligature-to-Unicode mapping produces.

| | 01 | 02 | 03 | 04 | 05 |
| --- | --- | --- | --- | --- | --- |
| Corrupted ligature stems | 0 | 0 | 0 | 0 | 0 |
| Type 3 bitmap fonts embedded | 0 | 0 | 0 | 0 | 0 |

### The defect this replaces, and its diagnosis

In the previous build, extraction produced *nite* for *finite*, *dierence* for *difference*,
*certicate* for *certificate*: 125 occurrences of mutilated stems across the five documents,
against 4 intact occurrences of the four target words. A codepoint dump showed the `fi`
ligature extracting as **U+001C**, the raw T1 (Cork) encoding slot, rather than as `fi`.

`pdffonts` showed the cause: the text fonts were embedded as **Type 3 bitmap fonts**. All
five preambles already contained `\input{glyphtounicode}` and `\pdfgentounicode=1`, but that
mechanism builds a `ToUnicode` map from glyph *names*, and Type 3 bitmap fonts carry none.
The preambles requested `\usepackage[T1]{fontenc}` without loading a T1 outline font, so the
distribution fell back to bitmapped fonts.

The diagnosis was confirmed by compiling two minimal documents containing the identical
sentence *finite difference certificate coefficient first field defined finding affine*:

| Case | Preamble | Extraction |
| --- | --- | --- |
| A | the previous preamble | `nite dierence certicate coecient rst eld dened nding ane` |
| B | the same plus `\usepackage{lmodern}` | `finite difference certificate coefficient first field defined finding affine` |

`lmodern` is now loaded in all five preambles, before `glyphtounicode`, with a comment
explaining why. `rebuild_all.sh` fails if the check ever regresses.

## 4. Figures

All nine figures of document 05 are regenerated by one script from files in
`sources/supplementary_results/data/`, which are verbatim copies of committed experiment
records.

| Property | Status |
| --- | --- |
| Output formats | vector PDF (used in the manuscript), SVG (archival), PNG at 300 dpi |
| Values entered by hand | none; every plotted value is read from an input file |
| Palette | Okabe–Ito, colourblind-safe; no red/green-only encoding |
| Sample counts | shown on the figure or stated in the caption |
| Plotting floors | stated on the axis wherever a logarithmic axis hides a value |
| Confidence intervals | none drawn, because no sampling model is specified for any of these experiments; ranges shown are observed minimum-to-maximum and are labelled as such |
| Manifest | `sources/supplementary_results/figure_provenance.json`, also copied to `verification/figure_provenance/` |

The manifest records, per figure: input files with SHA-256 and size; output files in all
three formats with SHA-256 and size; the SHA-256 of the generator itself; and the versions
of the numerical libraries used.

## 5. Tables and macros

Tables and numerical macros for document 01 are generated from the recorded registries, so
that no number in that manuscript is typed by hand.

Two generation steps are part of the build:

1. `scripts/regenerate_optimality_classification.py` re-derives the classification of
   enclosure outcomes from the recorded certified bounds. It is **idempotent**: running it
   twice produces byte-identical output. This was verified.
2. `scripts/sanitize_generated_tables.py` replaces implementation vocabulary in the
   generated LaTeX with standard terminology. It rewrites headings and labels only, never a
   numeric value, and exits nonzero if any forbidden token survives. Seventeen tables pass.

## 8. What was **not** verified

1. **No reproduction from a clean environment.** Neither case study has been rebuilt and
   re-run from a fresh environment as a dedicated exercise. This is the largest outstanding
   gap and is stated first in document 04's limitations.
2. **No independent party has reproduced anything.** Every agreement above is internal.
3. **No independent review of any proof.**
4. **No assessment of originality** for any statement.
5. **The continuous-integration status of case study II was not re-verified here.** Document
   04's account of it rests on records that would require network access to the hosting
   service to confirm; that check was not performed, and the corresponding claim is marked
   *unverified* in the reference verification file.
6. **The experiment pipeline was not re-run.** The numerical evidence for document 01 dates
   from source commit `b718f4e51785`, earlier than the manuscript text. Only the
   classification of already-recorded bounds was re-derived.
7. **Two bodies of specified work were not executed**: the extended optimiser grid of case
   study I (460 800 search trajectories) and two further sweep stages of case study II. Both
   are recorded as not executed rather than omitted.

## 9. Reproducing this package

```bash
bash rebuild_all.sh
```

Requirements: a TeX distribution with `latexmk`, `pdflatex`, `bibtex` and the packages named
in each preamble; Python 3.12 with `numpy`, `pandas`, `pyarrow`, `matplotlib`; poppler's
`pdftotext` and `pdffonts`.

The script performs no experiment. It re-derives the classification, rewrites the generated
table vocabulary, regenerates the figures with checksums, builds the five manuscripts from
clean directories, enforces the acceptance criteria of §§2–3 and fails if any is violated,
runs the case study I tests, and writes `checksums.sha256`.

Verification against the shipped package: compare `checksums.sha256` and
`sources/supplementary_results/figure_provenance.json` after a rebuild. The classification
re-derivation and the table rewriting are deterministic; the figure generator is
deterministic in its data but embeds a timestamp in the manifest, so compare the per-figure
checksums rather than the manifest as a whole.
