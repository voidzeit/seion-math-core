\section{Associator defects}

The associator energy is a normed, sampled quantity
\[
E_{\mathrm{assoc}}=\mathbb E\left[\left\lVert A_\mu(X_1,\ldots)\right\rVert^2\right],
\]
where the convention, input distribution, sample count, seed, dtype, and normalization are part of the certificate. A zero value for an associative-derived example is a finite calculation. A small value for a random or learned example is a numerical observation.

\begin{remark}
No generic ``associator score'' is reported without naming the exact formula. The five-input and anchored defects can disagree even for the same tensor.
\end{remark}
