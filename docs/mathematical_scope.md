# Mathematical scope

The package implements finite-dimensional vector-space laws with explicit coordinate tensors. It supports arbitrary arity `n >= 2`, with the ternary case specialized because it has several non-equivalent composition conventions.

The first paper tracks are deliberately limited to:

1. bounded/discrete kernel-integrated ternary laws;
2. structure-preserving projector reduction and closure leakage;
3. finite/truncated cohomological operators.

The package does not prove a continuum limit, a universal curvature equivalence, a physical field theory, or any application claim.
