# Decision: Paper 2 (finite projected n-ary mathematics) not written this pass

Mission section 6 asks for a second paper using "the strongest proved
finite core only" (typed composition trees, exact subset expansion, root
orthogonality, k/(k-1) bounds, tangent-normal calculus, path-sum
attribution, signed forests, associator constants, sharpness status,
novelty comparison) explicitly excluding any A-N empirical claim as proof.

That content is Track T (projected n-ary tree mathematics) plus the
existing v3/v4 finite-core material already registered in
`claims/theorem_registry_v3.yaml`, `claims/scope_registry_v4.yaml`, and
the existing `papers/tree_stability_v3` / `papers/tree_stability_v4`
sources. The user's accepted mid-campaign checkpoint explicitly deferred
Track T to a future session (`.ai/SPECTRAL_TRACK_ROADMAP.md`, "Deferred"
section).

Writing a new "v5" paper this pass would require either:

1. New proof work on Track T's open questions (sharpness, cancellation-aware
   constants) — explicitly out of scope for this session, or
2. Repackaging existing, already-published v3/v4 content under a new
   label — which risks implying new work happened where none did, and
   duplicates `papers/tree_stability_v3`/`v4` without adding anything.

Neither is appropriate given the deferral decision already made. This
paper is therefore **not written this pass**, by deliberate choice, not
oversight. It remains tracked in `.ai/SPECTRAL_TRACK_ROADMAP.md` under the
deferred Track T item for whenever that track is picked back up.
