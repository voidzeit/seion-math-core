The object

Projected multilinear trees

Compose bounded multilinear maps along a rooted tree and apply an orthogonal projector after every internal operation. This is the abstraction of any hierarchical compressed computation — tensor trains, hierarchical Tucker, tree tensor networks.

Each law has operator norm at most M. Its closure defect rho is the norm of its normal output on already-projected inputs. The single governing parameter is eta = rho / M, and constants are normalized against rho · M^(k-1) · L_T where L_T is the product of leaf norms and k the number of internal vertices.

universal bound E_amb <= k · rho · M^(k-1) · L_T E_proj <= (k-1) · rho · M^(k-1) · L_T exact decomposition E_amb^2 = E_proj^2 + E_normal^2, E_red = E_proj at the root

The missing root contribution is structural, not an estimate: the final projection removes the root's own normal defect exactly. That is why the projected coefficient is k-1 and not k — zero for a single vertex, one for two.

Topology dependence, made exact

For the restricted gated-rotation law the two k=3 topologies separate by an exact factor of three at their shared optimum:

chain E_proj = 3 eta² sqrt(1−eta²) best ratio 3/4 at eta* = 1/sqrt(2) branching E_proj = eta² sqrt(1−eta²) best ratio 1/4 at eta* = 1/sqrt(2)

Neither ever saturates. This corrected an earlier sampled minimum gap of 0.350 at eta = 0.5: the true continuous minimum is 1/4, at a point the sampling grid never tested.

Asymptotic sharpness for all k

M18 and M19: for every fixed full-binary shape, and then every finite arity-compatible shape, a two-dimensional witness gives E_proj = |sin((k−1)·arcsin eta)|. With the universal bound this proves

lim (eta ↓ 0) C_T(eta) = k(T) − 1

So local error accumulation is first-order sharp, while the finite-defect extremal geometry is strictly smaller than the universal coefficient. M3b/M3c/M3d give the exact all-k recurrence for the gated-rotation family: E_proj = |a(T)·cos(d(T)θ) − cos(θ)^k| with explicit recursive invariants a, d, independent of finite dimension and projector rank.

New this week

Geometry of projected rebracketings

If a projection can hide the difference between two bracketings of the same computation, then any observed associativity defect is suspect. These three constants say exactly how badly, in both directions.

For a rebracketing pair A = F_T − F_T' (ambient) and Â = R_T − R_T' (observed, compressed):

ConstantMeaningValueAttainedClass
C_2error inside one tree1yesprior (M8)
J_2distortion between trees2yesfree = same-mu = same-mu+shared-P
H_2concealment of a genuine defect2yessame witness as J_2
S_2fabrication of a spurious defectΣ₂(eta) < 2yesfree laws
Σ₂(eta) = sin( min(2 arcsin eta, π/2) ) / eta = 2 sqrt(1 − eta²) for 0 < eta <= 1/sqrt(2) = 1 / eta for 1/sqrt(2) <= eta <= 1 Σ₂(1/sqrt2) = sqrt(2) Σ₂(1) = 1

The asymmetry is the result. A projection can conceal an arbitrarily large rebracketing defect entirely — H_2 = 2, total concealment, at every leakage level, not a small-eta perturbative effect. But it cannot fabricate one of the same size: fabrication is sharp at Σ₂(eta) · rho·M·L < 2 rho·M·L. That yields a usable one-sided certificate,

‖P A‖ >= ‖Â‖ − Σ₂(eta) · rho · M · L

sharpening the naive threshold from 2 rho M L. The J_2 witness uses one ternary law and one rank-2 projector at all four vertices of both trees in ambient dimension 3, with every leaf inside Ran(P) — so the whole class hierarchy collapses at k = 2.

Verification. 123 witness audits, all passing, 19–28 checks each, over 41 values of eta in [0.025, 1.0]. Operator norms and closure defects are measured by alternating maximization with 400 restarts, brute-sweep stall detection, and matched to analytic values at 1e-9:

max | S_2 measured − Σ₂(eta) analytic | = 4.44e-16 (41 witnesses)

Two distinct transitions — do not conflate

eta_c^{S_2} = 1/sqrt(2) ≈ 0.707107 is the transition of Σ₂ at k = 2. eta_c^{W_3} = sqrt(2/3) ≈ 0.816497 is the transition of W_3 = C_3 at k = 3. Every occurrence of sqrt(2/3) in the repository belongs to the k=3 line and is correct.

S_2^same-mu remains Open with zero valid numerical evidence in either direction — see the retractions below.

Certificates

Computable bounds, and what they are worth

M24 — the telescoping expansion over effective slot maps is an exact identity, so all slack is attributable to how it is bounded, not to the expansion. Bounding per sample with exact slot operator norms gives ‖delta_v‖ ≤ B_v pointwise. M25 refines it: the closure residual lies in Ran(I − P_v) by construction, so the cross term sees only the normal component of the propagated error, giving

‖E‖ <= G <= B <= B̄ <= A

strict exactly when the closure residual is nonzero and the normal-restricted gain is strictly below the unrestricted one.

M12 — finite source-resolved error calculus. Every node error has an exact finite multi-index polynomial expansion; topological convolution agrees with recursive unrolling; same-source first-order paths aggregate before taking norms; truncations carry a norm-weighted omitted-term bound; and signed coefficient aggregation yields B_actual ≤ B_signed ≤ B_treewise. On DAGs this gives an O(|V|+|E|) source-resolved reverse dynamic program with no tree unrolling.

M5 / M5b — continuum. If the complete downstream-gain-weighted defect sum tends to zero, ambient and recursively projected root evaluations converge and every finite-N bound passes to the limsup. No uniform bound on vertex count is needed once the weighted sum is controlled.

1 — The instrument that nearly faked a constant

The GPU search normalized its objective by a feasibility factor computed under no_grad. Since J(cμ) = c²J(μ) forces ⟨∇J,μ⟩ = 2J > 0 while F(cμ) = F(μ) forces DF(μ)[μ] = 0, freezing F leaves the radial component uncancelled and the optimizer climbs a direction the constraint should have removed. Radial derivative measured 5.443e-01 frozen versus 7.633e-17 differentiable; finite-difference error 1.07e+01 versus 9.1e-06. The forward pass is scale invariant in both modes — no forward check could ever have caught it. All same-law evidence before commit 8843022 is void.

2 — The certification tax was a gauge artifact

The whole TT economics corpus was measured on non-orthogonalized trains. Re-running identical code on the right-orthogonalized representation of the same tensors (reconstruction agreement 2.12e-15) drove tau from 9.49 to 1.0000 at every percentile; over 20 240 meaningful rows cert/error ∈ [1 − 3.8e-13, 1 + 2.4e-12]. After canonicalization each slot map is an isometry, so the recursion is an equality — this is Oseledets' TT-SVD error identity, rediscovered. A formal gauge battery confirms it: an orthogonal gauge leaves tau at 1.0000, an ill-conditioned one moves it to 14.14 on an unchanged tensor, and re-canonicalization restores 1.0000. Hence kappa_intrinsic = 1 for TT chains.

3 — Branching died to its own control

Truncating each child by its own local SVD produced tau = sqrt(r1 r2 / r_p), confirmed across 33 configurations to 1.8%, with the falsifiable edge r_p = r1 r2 → tau = 1 holding in all 9 such cases. But HT-SVD and every TTN implementation truncate using the SVD of the tensor matricized at that edge, with the environment already folded in. Under that rule tau collapses to 1.005–1.022 at every node dimension. The amplification was a property of how you truncate, not of branching.

Also retracted with it: the certified TT allocator, the "certification premium collapses at tight tolerance" reading, the threshold + verifier + repair architecture, and both successive diagnoses of where the cost lived ("the margin is in allocation", then its replacement "the tax is caused by the certificate"). REACH-2 answered YES where REACH-1 answered NO — the restricted transport norm is 0.83–0.96 < 1 and a certificate charging it stays sound — but it recovered 10–15% of a gap that does not exist under the standard truncation.

The rule that came out of it

Before interpreting a quantity as geometry, identify the group of transformations under which it must be invariant, and test that first. The rule tightened after the third: it is not enough to ask "is this invariant under a change of representation?" — you must also ask "am I comparing against what the standard algorithm actually does?" All three times, the loss was against an impoverished version of the standard that had been built in-house.

What is genuinely there

Measured first order does strictly dominate full pairwise, rank-q pairwise and exhaustive step-greedy at m = 8 and m = 10 — both lower exact-terminal regret and fewer evaluations (regret 0.2298 at 60 evaluations versus 0.3867 at 228 and 342). Horizon-6 rollout lowers regret by 90.5% and 76.0% but consumes two to three orders of magnitude more evaluations; neither policy dominates the other. Both are Domain-limited to frozen bases, D=16 heterogeneous chains, six rounds, five exact-oracle seeds.

The register lists ten confounders blocking promotion. The binding ones: exact enumeration costs 235 348 profiles at m=8 and 3 039 400 at m=10, so the oracle is not a deployable policy; FLOPs, resident memory, VRAM, energy, data movement and SVD cost are all unmeasured; and the synthetic comparators keep bases frozen while a real library-native cutoff can refit bases and shrink ranks.

Held-out leakage

The KGE metrics were inflated by a factor of 2.5

Two trainers reused evaluation-time known-positive filter tables to mask hard negatives during training. Masking sets a candidate's score to −inf, so it can never be selected as a negative and the objective never pushes it down. Applied to a held-out split's gold entities, the model is being told, per query, which entity not to suppress.

Identical seed, config, eval subset and matched wall clock. The leak was worth +0.312 MRR. The honest TEST figures on 40 932 queries are MRR 0.19764, H@1 0.12802, H@3 0.21536, H@10 0.34022.

No file-access audit could have caught this

The sealed runtime sentinel correctly reported zero forbidden TEST accesses throughout, because the sealed trainer genuinely never opened TEST. The leak is in what the filter tables are used for. Establishing it for TEST required no TEST read — it follows from the code path. The historical MRR = 0.6116475 is now leakage-explained rather than unknown.

All seven affected trainers now expose a TRAIN-only negative filter sharing data.train_only_filter_view, with defaults preserving historical behaviour so old runs stay reproducible, and a standing statistical detector pinned by tests/kgr/test_no_heldout_leak_in_training_negatives.py. Twenty-nine TTN_FB15K237_* directories plus the SPECTRAL_MIXTURE, SRATM_DISCOVERY, V25_FB237 and KGR_V26 runs were produced under the leaking default; every predictive-quality metric from them must be re-run or withdrawn. Certificates and rank/spectral diagnostics computed on those checkpoints remain true of those tensors.

The magnitude is model-dependent and that is itself a finding: the same leak cost SRATM 0.31 MRR but TTN almost nothing (+0.00144), because a model too weak to exploit the exemption cannot benefit from it. The leak is dangerous precisely in proportion to how good the model is.

Infrastructure

The instrument

The falsification apparatus is the part of this project with the clearest transferable value, and it is what caught all three self-inflicted retractions.

  • Structural invariance gates. Radial-null and finite-difference checks on the backward pass; envelope-theorem identity |⟨∇N,μ⟩ − N| = 2.665e-15; a gauge battery over orthogonal, ill-conditioned and re-canonicalizing transformations, each verified to preserve the represented tensor before any reading is taken; dimensional-monotonicity checks that caught non-convergence in the same-law class while the free control passed.
  • Positive controls with known exact answers. The free class attains Σ₂ by theorem, so its shortfall at any budget is the optimizer's noise floor — calibrated at 0.9914–1.0000 across ambient dimensions 2, 3 and 4.
  • Fail-closed by default. Any certificate falling below a true error aborts the run rather than being reported.
  • Regression tests for the bugs themselves. test_frozen_normalization_is_detectably_wrong fails if the gradient bug returns; test_no_heldout_leak_in_training_negatives pins the KGE detector.
  • One mathematical engine, many campaigns. Convergence studies orchestrate the canonical harness as a subprocess rather than reimplementing it — reimplementing the search to study the search is how the frozen gradient survived as long as it did.

Hardware. RTX PRO 5000 Blackwell Laptop (24 GB, 82 SMs, CC 12.0, CUDA 12.8, torch 2.12) and Intel Core Ultra 9 285HX (24 cores, 127 GB). All arithmetic float64: at these tensor sizes the run is launch-bound rather than FLOP-bound, so lower precision would buy almost nothing while introducing a precision question into a run whose purpose is to test a certified bound. Fusing objective, class, rank and eta into per-element vectors took the sweep from 42% GPU utilization at 2.0/24 GB to 100% at 24 GB; the witness audit runs 123 audits over 41 eta values in 15 s on 24 cores.
