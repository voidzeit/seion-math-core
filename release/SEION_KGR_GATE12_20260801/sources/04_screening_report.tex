\section{The A0/A3 comparison is confounded --- stated before interpretation}
A3 trained on a 5{,}000-triple subsample (1.8\% of FB15K-237's, 5.8\% of WN18RR's full training
split) for 3 epochs; A0 trained on the full split for 5 epochs. This deviation was logged in
\texttt{preregistration.md} \S11 \emph{before} any A3 result was generated (a live timing probe
showed the full-scale A3 configuration did not complete one epoch in over 8 minutes; see
\texttt{09\_negative\_results.pdf}). \textbf{The large MRR gap
between A0 and A3 must not be read as evidence about the path/seionic branches} --- a
same-data-scale, same-epoch-budget comparison was not executed.

\section{Compute}
All A0 runs used the real RTX PRO 5000 Blackwell (GPU faster for pure-GEMM base-expert scoring).
All A3 runs used CPU (GPU was measurably slower for the path reasoner's per-sample workload during
the timing probe --- see \texttt{09}). No VRAM/host-RAM profiling was collected in this campaign
(a real gap, listed in \texttt{09}).

\section{Statistical treatment}

\texttt{preregistration.md} \S9's explicit instruction that this would misrepresent a 2-point
sample as a distributional estimate.
